Install in Chrome

Four steps. Developer mode is required until this is on the Chrome Web Store.

  1. Download and unzip gravity-force-extension.zip.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Load unpacked and select the folder that contains manifest.json.

Toolbar icon or Ctrl+Shift+G / ⌘⇧G opens the popup. Ctrl+Shift+Y / ⌘⇧Y scans the current GeForce NOW page for Mbps labels.
